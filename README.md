# 老赵市场工具箱官网

这是「老赵市场工具箱」官网的静态源代码，托管于 GitHub Pages。

线上地址：<https://zhaotools.github.io/LZ-Market-Toolkit/>

## 文件说明

- `index.html`：网页结构与内容
- `styles.css`：网站主体样式
- `app.js`：工具体系切换、移动端导航与页面动效
- `dca-blue.css`：LZ-DCA 蓝色主题样式
- `tool-visuals.css`：四套工具专属简图样式

## 本地查看

可以直接用浏览器打开 `index.html`，也可以在项目目录运行静态服务器：

```bash
python3 -m http.server 8080
```

然后打开 <http://localhost:8080>。

## 说明

网站为纯静态页面，不依赖数据库或后端服务。
